# capitalengine-api

The public API of **CapitalEngine**, a modular economy for Paper servers: binaries and Javadoc only.
CapitalEngine itself is closed source. You may compile against this API under the terms in [API-LICENSE.txt](API-LICENSE.txt).

- Javadoc: https://patelheet30.github.io/capitalengine-api/docs/latest/
- Releases: https://github.com/patelheet30/capitalengine-api/releases

## Use it

```kotlin
repositories {
    maven("https://patelheet30.github.io/capitalengine-api/m2")
}
dependencies {
    compileOnly("com.patelheet:capitalengine-api:<version>")   // see Releases for the latest version
}
```

In your `plugin.yml`: `depend: [CapitalEngine]`. Then:

```java
CapitalApi api = Bukkit.getServicesManager().load(CapitalApi.class);
if (!api.isCompatible("1.0.0")) { getLogger().severe("Needs CapitalEngine API 1.0+"); /* disable */ }
```

The API follows semantic versioning: minor versions only add things, and breaking changes happen in major versions.
Published versions are never changed or removed.

## About this repository

Everything here is generated by the release pipeline of the private CapitalEngine repository. Pull requests named
`release/api-<version>` are opened automatically; merging one publishes that version. Please don't edit files by hand.
